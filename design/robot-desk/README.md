# 机器人桌搭设计预览

更新至 2026-09-22。视觉沿用已获用户确认的 v18；v20 设置增加自动切换开关；自动轮播以原生验证为准，浏览器仍用于手动布局预览。最新预览为 `v5/index.html`，`index.html` 会跳转到新版；`index-v2.html` 保留历史讨论稿。建议通过项目根目录的本地 HTTP 服务查看，以避免 file URL 的资源限制。它不连接手环或外部服务，Codex 数据是明确标注的示例。

## 当前设计要求（真机验收另记）

- 名称“机器人桌搭”，原创薄荷色机器人图标。
- 眼睛和四个手势统一为白色主题，手势以黑色指缝保持轮廓清晰；时钟薄荷青、七天日历暖金、周末珊瑚色，设置使用彩色卡片。
- 双眼使用 128×128 显示槽，默认静稳，特定情绪短暂点头／左右动作。全部页面取消统一中央安全区；文字铺开，确认按钮位于两端弧区。
- 26 种动作，加入颜文字眼形和 OK／点赞／挥手／胜利手势；双连眨眼、重复单眨、双次心跳、连续落泪和星光闪烁。
- 日历班／休位于下方，节日名优先，连续官方休假用相连绿色底条；设置为固定轮廓的常亮／自动切换／退出，无标题、无翻转。
- 第四张 Codex 页使用黑底、绿色额度环、白色百分比、ChatGPT Logo 和 Business 5×；整行文字对齐，隐藏刷新提示但保留双击。无数据、断连、过期有文字状态。
- 左右切桌面、上下开关设置，卡片随指移动，松手后短距离归位或回弹。点击动作按钮可逐一查看，随机／暂停可切换。

预览和 Vela 设备使用同一套基础眼形、动作数据和时间插值。设备图片预先旋转、文字使用位图字形；v5 胶囊内同样复用物理 PNG、布局和动作数据，胶囊外的说明／操作按钮由浏览器绘制。设备分页使用原生 swiper，预览使用浏览器拖动插值，二者的渲染和时序不等价。`scripts/generate-robot.mjs` 生成原图和动作；`scripts/generate-preview.mjs` 生成 v5/shared.js。Vela 不运行网页。实际帧率、弧边、手势与耗电须在 Band 9 上验收。

## 开源参考与实际复用

1. [FluxGarage/RoboEyes](https://github.com/FluxGarage/RoboEyes)：GPL-3.0，面向 Adafruit GFX/OLED。已有圆角眼、自动眨眼、随机巡视、开心/困倦/生气及笑/疑惑动作。用于比较眼形和动作能力；本预览没有复制其代码或素材。
2. [tanmaywankar/Grobot_Animations](https://github.com/tanmaywankar/Grobot_Animations)：MIT，面向 TFT_eSPI。具有圆环眼、眼睑和弹簧插值。历史原型 `index-v2.html` 的 `spring()`、圆环绘制/眼睑思路及圆环情绪参数改编自此项目，尺寸和节奏重新适配胶囊屏；版权和完整许可保存在 `Grobot-LICENSE.txt`。固定参考提交 `858d8da648c9e71ff9b9f5e6f558ba85293a70fb`。该项目名称不代表它是 xAI Grok 官方实现。
3. [playfultechnology/esp32-eyes](https://github.com/playfultechnology/esp32-eyes)：GPL-3.0，Cozmo 风格，参数化眼形和自动眨眼/视线，作为备选对照；未复制代码。

圆角眼/像素眼、布局、交互和调度代码为本项目编写。没有将 GPL 上游的第三方 Web 移植版所标注的 MIT 当作原始库许可，也没有引入浏览器框架或在线素材。

## 实现和验证

0.2.0 用户反馈真机动画几乎不动。新方案不再使用整幅图片序列，详见 [技术方案](../../docs/robot-technical-plan.md) 与 [验证记录](../../docs/validation.md)。HTML 中的常亮、自动切换开关与退出只是演示，不控制电脑或设备。

## 手势和眼形素材

四个手势复用 Twitter Twemoji 14.0.2（1f44c／1f44d／1f44b／270c），图形为 CC BY 4.0。保留原 SVG、包内许可和署名，构建时改为纯白主体和黑色指缝，删除挥手图标的印刷运动线，并给点赞补充掌指分界。96×96 透明画布留 5px 内边距，避免指尖贴边；设备仍只读取预生成的 PNG，不进行 SVG 解析、重绘或旋转。来源 https://github.com/twitter/twemoji/tree/v14.0.2 。

原创眼形采用统一的圆角、圆头线条和白色实体：开心弯眼的弧度更柔和；螺旋改为更疏的 1.675 圈；委屈眼保留较厚白边和两处高光；怒眼使用完整闭合轮廓，圆眼、挤眼和叉眼减少尖角与细线。这些是设计与构建定义，真实大小下的辨识度仍需 Band 9 用户验收。

新预览直接复用物理资源及排布函数。素材输入变化后执行 npm run robot:assets；只有共享预览逻辑变化时使用 npm run preview:assets。

## 预览维护

当前入口 v5，index.html 只做跳转。v3/sprites.html 虽在旧预览目录，仍是素材生成器的输入，不可直接清理。修改共享逻辑后执行 npm run preview:assets；修改资源时使用项目开发指南中的对应生成命令。检查 390px 等窄屏时确认整个胶囊在视窗中，不能只检查网页是否横向溢出。
