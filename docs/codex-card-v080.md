# 0.8.0 Codex 额度仪表重设计

> 历史视觉方案：当前实现已改为 [0.8.1 纯黑额度页](codex-card-v081.md)。

日期：2026-09-22。目标设备为 Xiaomi Smart Band 9 NFC / M2346B1 / OS 3.1.32，物理屏幕 192×490；本文按用户观看的 490×192 横屏逻辑坐标描述。0.8.0 / v16 已安装并由设备列表确认，新增视觉尚待用户真机验收。统一产品要求见 [Codex 需求规格](codex-requirements.md)。

## 目标

- 第一眼先读到剩余额度，再读套餐、重置时间和数据状态。
- 使用完整胶囊轮廓，不把内容重新压回中央矩形安全区。
- 以低发光 OLED 深色界面营造高级感，同时保证小屏高对比和低密度。
- 套餐必须来自 Codex App Server 的真实 `planType`；缺失时显示 `CODEX`，不推断或写死倍率。
- 保留全屏双击刷新、独立 loading、缓存／过期状态和原生 swiper，不新增会拦截分页的覆盖层。

## 视觉层级

1. 左侧 150×150 分段环形仪表是主视觉，按 5% 一档点亮，环内显示精确整数百分比。
2. 右上为 `CODEX` 标识和套餐徽章；当前 `self_serve_business_prolite` 映射为 `BIZ PRO LITE`。
3. 右侧中部显示重置倒计时；下方用细轨道再次表达剩余额度，便于快速扫视。
4. 底部只保留更新时间和“双击刷新”，刷新时只在右下显示 26×26 loading，不重建整页。

## 色彩与形态

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| OLED 背景 | `#020617` | 最外层和大面积底色 |
| 深蓝面板 | `#071522` / `#0B2130` | 胶囊内层和仪表轨道 |
| 主强调 | `#62F2CF` | 剩余额度、正常状态 |
| 次强调 | `#72B6FF` | 套餐徽章、仪表渐变 |
| 主文字 | `#F8FAFC` | 百分比和关键信息 |
| 次文字 | `#9AB7C6` | 标签、更新时间 |
| 警告 | `#FF9D87` | 过期／断连状态 |

效果只使用固定背景中的轻量径向光晕、细轮廓和点阵，不使用持续动画、模糊层或运行时旋转。仪表和所有文字仍在构建期生成预旋转 PNG。

## 数据与降级

- 在 schema v1 的 `payload` 中新增可选 `planType`，属于向后兼容扩展；旧快照仍可正常显示。
- Mac 从所选 Codex 额度桶读取官方 `planType`，仅转发枚举值，不转发账号 ID、邮件、Token 或凭据。
- 手环只接受已知套餐枚举并映射短标签；未知值统一显示 `CODEX`，避免把后端内部字符串直接挤进小屏。
- `20×` 当前不属于本机 App Server 额度响应字段，因此本版不展示。后续只有协议出现可信倍率字段时才增加。

## 验证

- 逻辑：套餐解析、未知套餐降级、环形仪表量化、旧 schema v1 兼容。
- 视觉：0%、1%、59%、100%、无数据、断连、过期、loading，检查胶囊两端、字形完整性和持有指针帧。
- 交互：全屏双击只触发一次；短拖、慢拖、取消和原生分页不误刷新。
- 构建：`npm test`、`npm run build`、AppKit Clang 构建／签名；模拟器只证明布局与启动，不替代真机验收。
