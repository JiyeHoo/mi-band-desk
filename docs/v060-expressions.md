# 0.6.0 表情与动作重设计

2026-09-20；用户要求重新设计不合适的表情，手势使用白色，并为每个表情设计对应动作。版本 0.6.0 / versionCode 12；安装状态见 [交接](handoff.md)。

## 视觉与动作

四个手势改为白色主体、黑色指缝，移除 Emoji 印刷运动线；沿用 Twemoji 原 SVG 并保留 CC BY 4.0 署名。笑眼、怒眼、圆眼、螺旋、可怜眼和挤眼等统一圆润粗线。心、腮红、泪滴与星点仍可彩色；日历和设置配色未改变。

## 性能与兼容

- 继续使用物理坐标、预旋转 PNG 和整数非零眼睑；不使用原生 transform、旋转或复杂关键帧。
- `gaze=[percent,x,y,tilt]` 中 tilt 通过左右眼相反的高度变化表现歪头，不旋转父层。附着的腮红／泪滴按对应眼睛移动。
- 眼睛保持 128×128；手势为 76×76。全部特效 scale=1，帧间只改变位置和透明度，不反复缩放解码。
- 活动段仍按 60 次/秒预算采样并跳过迟到帧；静止段等待下一活动边界，最长 1 秒。此预算和日志不代表设备 FPS。
- 修复静止等待终态遗漏：`owo` 4250ms 处可能与上一回调落到相同浮点帧号，现在长等待前强制采样终态，使已睁开眼睑立即透明。
- 保留触摸暂停、原生 swiper 分页、有限防误触、hide/destroy 清理和常亮释放。

小米官方依据：[常用业务优化](https://iot.mi.com/vela/quickapp/zh/guide/best-practice/business.html) 建议减少动态样式、回流和图片缩放；[image](https://iot.mi.com/vela/quickapp/zh/components/basic/image.html) 仍使用已支持的图片能力，未新增设备 API。
