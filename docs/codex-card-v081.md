# 0.8.1 Codex 纯黑额度页

> 真机视觉已被用户否定。当前设计见 [0.8.2 环形额度页](codex-card-v082.md)。以下为历史方案。

2026-09-22。替代 0.8.0 的环形仪表设计；Mac 0.8.0、AstroBox 插件 0.7.5 和 schema v1 沿用。安装和验收结果以 [handoff.md](handoff.md) 为准。

## 视觉和信息

用户要求完全重新设计，采用与其他桌面一致的纯黑底，不要装饰背景、描边或卡片。主次用字号、位置和少量颜色区分，不再绘制环形仪表、进度轨道、渐变、发光、网点或套餐胶囊。

- 左侧：88px 薄荷绿数字，34px 百分号贴近基线；下方 22px「本周剩余」或实际窗口「5小时剩余」。0、1、59、100 和缺省横线共用字号，按数字宽度居中。
- 顶部：左侧 CODEX，右侧 17px 淡紫套餐文字。套餐依然只映射实际字段，不推断倍率；未知字段显示 CODEX。
- 右侧：18px「距离重置」、27px 倒计时、18px 新鲜度和 17px「双击刷新」。断连／过期用暖橙文字，历史值保留。
- 主数据表示真实剩余额度百分比，不是现金余额。协议没有货币余额字段，本页不编造货币值。
- loading 仍为右下 26×26 的独立预旋转图；不重建静态文字，不增加触摸覆盖层。

配色：背景 `#000000`，额度 `#80e7cd`，主文字 `#f4f6f5`，套餐 `#c2b5f5`，辅助 `#a1adab`，刷新提示 `#8b9795`，异常 `#ffae8f`。

## 胶囊几何

逻辑 490×192，物理 192×490。坐标源在 `src/common/layout.js`，显示资源源在 `scripts/physical-assets.mjs`；图片仅在构建时旋转，不新增原生 transform。上、下行避开端部急弯，中部大数字利用较宽区域，不恢复统一中央矩形安全区。

本页删除旧全屏彩色底图和 21 档环形 PNG，保持原生分页和所有快照、缓存、排序、ACK、双击逻辑。测试中删除的进度矩形用例对应已移除功能，不意味着跳过现存功能验证。

## 复现检查

执行 `npm run physical:assets`、`npm test`、`npm run build`。浏览器预览使用设备相同的字形和坐标：

- `design/robot-desk/v5/index.html?remaining=100`：百分比极值；支持 0、1、59、100。
- `?state=empty`／`?state=stale`／`?state=disconnected`：无数据、过期、断连。
- `?remaining=87&window=300&reset=3500000&plan=unknown`：短窗口、分钟倒计时、未知套餐。

以上仅为浏览器样例，不会注入设备包。正式包保持真实系统时间和通信接口。原生模拟器截图、安装身份和真机反馈分别追加至 [validation.md](validation.md)。
