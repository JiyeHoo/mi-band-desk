# 机器人桌搭技术方案

2026-09-20。当前 0.5.0 方案见 [本轮改动方案](../v050-plan.md)，安装状态见 handoff.md。用户已经确认 0.4.1 黑线消失。以下保留 0.4.1 绘制方案的技术背景；动作数、设置和转场以 0.5.0 为准。

## 视觉与交互

- 眼睛保持白色；固定双眼中心 (165,96)、(325,96)，显示槽 128×128。取消整脸左右漂移和运行时眼睛旋转。
- 14 种动作：自然眨眼、双连眨眼、认真凝视、笑眼连眨、好奇挑眉、惊讶睁眼、困困慢眨、俏皮双眨、怦怦比心、眼泪哗哗、害羞笑眼、闪亮星星眼、气鼓鼓、迷糊连眨。通过眼睑和不同眼形表达，不用整脸摇晃代替情绪。
- 双眨有两个独立闭合／睁开动作和自然停顿；单眨同样重复两次。爱心按两次心跳放大，泪滴每 900ms 落下，星光独立闪烁。情绪每 8 秒更换，点击也可回应。
- 取消 x=108..382 的统一中央安全区。各页可用完整 490×192 胶囊；只考虑真实弧形轮廓，不增加统一文字内缩框。
- 时钟 96px，日期标题 28px；七天日历周名 26px、日期 34px，横向覆盖 x=22..468。今日暖金、周末珊瑚、时钟薄荷青。
- 设置卡片宽 144px，名称 30px、有效状态 26px。移除“24 小时制”“今天”重复行、“下滑返回”“需确认”等小字；申请失败仍在常亮卡片中以大字显示。
- 退出页只有中间 36px 的“退出桌搭？”。左侧 92×192 红色胶囊端部叉号取消，右侧 92×192 薄荷色端部勾号确认，形状沿屏幕半径 96 的圆弧绘制。
- 显示／点击共享 `layout.js` 矩形并分别生成两种方向的物理点击区；仍只有确认退出才能 terminate。常亮默认关，30 分钟／2 小时到期释放。

## 帧率依据与实现

[小米手环 9 官方规格](https://www.mi.com/hk/product/xiaomi-smart-band-9/) 标示 60Hz，脚注同时说明不同界面刷新率可能不同。[Vela 框架概述](https://iot.mi.com/vela/quickapp/en/guide/) 描述 60fps 渲染能力。这不是 OS 3.1.32 上本应用实测 60fps 的证明。

从 40ms／约 25 次更新每秒改为 1000/60ms 时间预算。调度基于绝对经过时间，补偿计算耗时；迟到直接跳帧，不堆积补帧；同一时间格只写一次，避免原生计时器提前触发产生重复更新。只写变化的属性。每个情绪结束记录一次 JS 更新频率与最大间隔，用于定位卡顿；这个指标不称作屏幕显示 FPS。

不依赖未核实的 Canvas、requestAnimationFrame 或新 API。使用 Band 9 路线中已有的 image/div、原生样式和 JS 计时器。离开眼睛、hide/destroy/退出均取消调度；会话代号拒绝迟到回调。

## 黑线处理及证据边界

用户确认首次打开页面正常，动画更新或点击常亮按钮改变文字后出现黑线。这将问题范围扩展到全页面的共同刷新路径。0.4.0 仍把整个 490×192 内容层旋转，设置文字与眼睑都需要经过该层局部重绘。PRE 4.0 未复现持续黑线，确切的固件渲染原因尚未证实。

0.4.1 从结构上绕开该路径：

1. 页面和卡片直接使用 192×490 物理坐标，不含任何原生 transform。layout.js 将横屏逻辑矩形同时映射为显示区与点击区；转场位移同样映射为物理方向。
2. 图形在生成资源时预旋转，翻转使用另一组 PNG。8 种固定黑底眼形继续使用 128×128 槽；黑色眼睑按整数像素定位，完全打开用 opacity=0，避免零尺寸原生遮罩。
3. 设置按钮的底色、名称和状态一起生成整卡图片；关／申请中／失败／30 分／2 小时分别覆盖整个按钮。标题、退出文案同样使用预旋转图片。
4. 时钟、日期和七天日历使用有限字形集合，按字符拼接，文字更新只替换相应图片。不缩小字号、不增加中央安全框。字形定义及颜色在 scripts/physical-assets.mjs 中维护；新文案／语言必须同步补充字形并重新生成。
5. 粒子继续使用少量独立小图；情绪切换明确清空不再使用的粒子及遮罩。仍按 60 次/秒预算调度，不用逐帧重载整屏图片。

该实现扩大了包内图片数量，RPK 约 329KB，换取不依赖运行时旋转。实际真机内存、流畅度及黑线结果须安装后复测。证据与复测范围见 black-line-fix.md。

## 转场、资源及验证

继续保留 0.3.1 的 160ms 淡出＋260ms 淡入，以及 CARD_REST 显式归位、独立完成任务、过期恢复、旧回调失效机制。详细复现见 `transition-fix.md`。根 scroll 和输入 scroll 均关闭双轴滚动。

`npm run robot:assets` 生成 15 张原始图形，以及两方向共 170 张预旋转图形／字形／按钮；无需整幅帧序列。`npm run physical:assets` 可单独生成物理资源。启动器图标规格、包名和签名身份不变。预览入口仍为 `design/robot-desk/v3/index.html`，页面标题显示 0.4。

验证包含 31 项逻辑测试、RPK 清单／CRC／资源／私钥排除、原生模拟器连续帧、两方向四向手势、端部按钮点击和两步退出。模拟器是 PRE 4.0，不代表 Band 9 的 OS 3.1.32。AstroBox 更新前须核对唯一目标为 Band 9 NFC、队列为空；更新后核对设备应用列表版本。
