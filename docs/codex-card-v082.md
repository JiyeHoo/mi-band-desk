# 0.8.2 Codex 环形额度页

2026-09-22：用户已确认本版真机「效果不错」；v19 沿用本视觉并新增轮播。此前用户明确否定 v17 真机 UI 的字号、颜色、对齐与套餐显示，要求重新设计。本文替代 [v17 方案](codex-card-v081.md)，不是对其验收通过的补充。

## 最终视觉

- 纯黑底；没有装饰底图、描边卡片、渐变或发光。保留用户新要求的环形进度。
- 左侧 168×168 环，6px 绿色进度，从正上方顺时针表示 0～100% 剩余额度。环内 54px 白色数字、25px 同基线百分号，下方 18px「本周剩余」或真实短窗口。
- 右侧 36px 白色 ChatGPT Blossom 图标，26px `Business 5×`；下方 24px 重置时间配时钟小图标，21px 更新状态配状态点。套餐和两行正文统一左对齐到逻辑 x=263。
- 隐藏「双击刷新」文字，保留原来的整页双击手势及刷新时 26×26 的独立图标。
- 只用白色主体、浅灰辅助、绿色额度环；异常状态以暖橙文字明确显示。无数据用横线和空环，断连／过期保留旧值并明确标记。

## 字形与资源

v17 把英文拆为定宽单字符 PNG；本版改为整行预排版，保留自然字距和同一基线，设备只按原尺寸显示。整张环形数字也在构建期一次绘制，不在设备逐字符重排。正常页面只有环、窗口、Logo、套餐、重置、状态六张独立小图，刷新动画不重建这些图。

新资源统一 `codex-v082-*` 文件名，避免同名图片跨版本尺寸或颜色变化造成缓存混淆；这不是已证明 Vela 缓存导致 v17 错乱。PNG 采用无损压缩；不超过 256 种 RGBA 颜色时使用精确索引色，不做量化。生成脚本逐像素检查优化前后完全相同。窗口文字图片透明，避免矩形黑底遮住环线；其余无重叠行使用纯黑底。

源定义：`scripts/codex-art.mjs`、`scripts/generate-physical.mjs`；位置：`src/common/layout.js`；资源映射：`src/common/physical-ui.js`。额度环精确生成 0～100，各类有效重置文案有对应整行资源；新增回归覆盖所有小时／分钟边界和正反向资源可用性，避免缺图造成黑页。

## 套餐与图标依据

用户在本任务中明确确认「已确认，显示 Business 5×」。本版为当前 `self_serve_business_prolite` 显示 `Business 5×`；倍率是用户确认的信息，不是从剩余百分比或一个不存在的倍率字段推算。其他 planType 映射为正常大小写短名称；未知显示 ChatGPT。

[OpenAI 官方定价](https://learn.chatgpt.com/docs/pricing) 说明 Business ($100) 使用 Pro 5x 额度估算，但该说明本身不证明某个账号已购买此档位。保留用户确认作为本账户显示依据。

Blossom 使用已安装官方 ChatGPT App 的公开 SVG 素材，白色等比栅格化为 36×36；源文件保留在 `scripts/vendor/openai/chatgpt-blossom.svg`，包内有 `common/licenses/OpenAI-NOTICE.txt`。仅用于标识额度来源，应用仍为独立的「机器人桌搭」，参见 [官方图标规范](https://openai.com/brand/)。

## 验证与交付边界

- 构建期整行宽度检查、额度极值与正反向素材完整性、胶囊实际像素越界检查。
- 浏览器 0／1／59／100、无数据、短窗口、过期、loading。
- 专用 PRE 的有数据 UI 使用明确标记的模拟器探针；探针不落缓存、不发 ACK。移除探针后重新构建正式 RPK，设备只安装正式包。
- 设备版本、插件恢复、原生测试与用户真机验收分别记录在 [validation.md](validation.md) 和 [handoff.md](handoff.md)。不能再以浏览器截图替代用户真机反馈。
